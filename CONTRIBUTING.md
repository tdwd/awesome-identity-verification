# Contributing

Suggestions are welcome! To add a resource:

1. Fork this repository and add your entry in the relevant section, keeping alphabetical-ish order within the section.
2. Format: `[Name](https://link) — one-line factual description.`
3. Open a pull request explaining why the resource is useful.

Guidelines:

- Resources must be directly relevant to identity verification, KYC/KYB, AML, or biometrics.
- Descriptions must be factual — no superlatives, rankings, or unverifiable claims.
- No affiliate links.
